# map-mieru

**日本全国の訪問した市区町村を色塗りし、都道府県ごとの制覇率を記録するWebアプリ**です。スマートフォン・PCのブラウザで使えます。

- [サイトの公開設定（GitHub Pages）](#公開方法)
- [Googleマップのタイムラインを取り込む](#タイムラインからの訪問候補取込)
- [データの扱いと注意事項](#データとプライバシー)

## できること

- 日本地図で訪問済みの市区町村を確認する
- 都道府県を開き、地図タップまたは市区町村一覧から訪問済み／未訪問を切り替える
- 全国の訪問済み市区町村数と制覇率、47都道府県ごとの達成率を表示する
- 地図をドラッグ・ピンチ／ホイール操作で拡大縮小する
- 端末のブラウザに記録を自動保存（localStorage）
- 訪問記録をJSON形式でバックアップ／別端末へ統合
- Googleマップのタイムラインから「5分以上の滞在地点」を検出し、**確認画面で選んだ市区町村だけ**を登録する（試験版）

市区町村データは**2026年1月1日**基準です。政令指定都市は市単位、東京23区は区単位です。

## 公開方法

依存関係のインストールやビルドは不要です。リポジトリのトップにある `index.html` をGitHub Pagesで公開できます。

1. GitHubリポジトリの **Settings → Pages** を開く。
2. **Build and deployment** の **Source: Deploy from a branch** を選択する。
3. **Branch: main / (root)** を選び、Saveする。
4. デプロイ後、`https://rmatsuoka-jpn.github.io/map-mieru/` からアクセスする。

※ ブランチ上で開発している間は、mainにマージされるまで公開版には反映されません。GitHub Pagesの初回有効化はリポジトリの設定画面から行ってください。

ローカルで動作確認する場合は、リポジトリ直下で `python -m http.server 8000` を実行し、`http://localhost:8000/` を開いてください。地図データ・地図表示ライブラリはCDNから読み込むため、**ネット接続が必要**です。

## タイムラインからの訪問候補取込

### iPhone / iPad

Googleマップアプリ → プロフィール → 設定 → 個人的なコンテンツ → タイムライン データをエクスポート → ファイルに保存。`location-history.json` が出力されます。

Google公式：<https://support.google.com/maps/answer/6258979?co=GENIE.Platform%3DiOS&hl=ja>

### Android

端末の設定 → 位置情報 → 位置情報サービス → タイムライン → タイムライン データをエクスポート。

Google公式：<https://support.google.com/maps/answer/6258979?co=GENIE.Platform%3DAndroid&hl=ja>

### アプリでの操作

1. 画面上部の「データの入出力」を開く。
2. 「タイムラインJSONを選ぶ」で書き出したJSONを指定する。
3. 市区町村の境界との照合が終わるまで待つ。
4. 取り込み候補を確認して、訪問済みとして登録したい市区町村を選ぶ。
5. 「選択した候補を登録する」を押す。

**試験版の対応形式**：`semanticSegments` 配列（または同形式の配列）に含まれる、`visit.topCandidate.placeLocation.latLng` を持つ滞在履歴。開始・終了時刻から滞在時間を計算し、5分以上のみ候補にします。移動中の `activity`、`timelinePath`、`rawSignals` は含めません。Googleのエクスポート形式は変更される可能性があります。未対応形式のときは実ファイルの個人情報を除去した最小サンプルで確認してください。

**精度上の限界**：位置座標と市区町村境界の点内判定で照合します。まず全国の簡略地図でおおよその地域を判定し、該当都道府県の詳細地図で再照合しています。そのため、道路・海岸・市町村境界付近、小島などでは隣接自治体への誤判定や取りこぼしが起こりえます。インポート結果は必ず確認してください。滞在5分以上も「実際に訪問した」と等価ではありません。

## 集計のルール

- 分母：本プロジェクトの2026年境界データ上にある国内の **1,741市区町村**。
- 市区町村単位で訪問済みか否かの2段階。訪問済みの市区町村は1回だけ集計。
- 県別の制覇率 = その県内の訪問済み市区町村数 ÷ その県内の市区町村数 ×100。
- **集計対象外**：行政区域コード末尾が000の所属未定地（7件）、北方領土の6村。全国境界データの1,754区域からこの13区域を除外。市区町村の数え方は自治体統計の慣行に合わせています。
- 行政区域の廃止・再編があった場合のコード引き継ぎは現時点で未実装。将来データ更新時に移行設計が必要です。

## データとプライバシー

- **サーバー・Googleアカウントへのログインは不要**。
- 訪問済みの5桁市区町村コード、記録方法、登録時刻だけを、利用者のブラウザの `localStorage` に保存。
- GoogleマップのタイムラインJSONはブラウザ内のJavaScriptで読み取り、**どのサーバーにもアップロードしません**。生の移動履歴・GPS座標は保存しません。
- 地図を表示する際に、公開の地図境界データをCDNから読み込みます。ブラウザとCDN間の通常のアクセス情報は発生しますが、入力したGPS座標や訪問済みデータは送信しません。
- **閲覧履歴削除、プライベートブラウズ、端末変更では保存内容が消えます**。必ずJSONバックアップを取ってください。
- **位置履歴をGitHubの公開リポジトリにコミットしないでください**。このリポジトリはプログラムと公開地図データへのリンクだけを持ちます。

## 技術構成

- HTML / CSS / Vanilla JavaScript（ビルド不要）
- D3.js 7 + topojson-client 3（CDN）
- GitHub Pages
- Map data: [ricewin/simplify-japan-geojson](https://github.com/ricewin/simplify-japan-geojson)、2026年1月1日時点の市区町村データを簡素化したTopoJSON（特定コミットに固定）
- 元データ：国土交通省「国土数値情報（行政区域データ）」

## 地図データ・ライセンス

地図の元データ：**国土交通省「国土数値情報（行政区域データ）」** <https://nlftp.mlit.go.jp/ksj/>

加工データ：**ricewin / simplify-japan-geojson** <https://github.com/ricewin/simplify-japan-geojson>

同データは CC BY 4.0 ライセンスで公開されています。出典表記を維持してください。簡略化されたポリゴンのため、行政上の正式な境界判定には使用しないでください。D3.jsとTopoJSONライブラリは各ライセンスに従います。
